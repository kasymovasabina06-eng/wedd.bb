TELEGRAM КООПСУЗДУГУ
GitHub Pages — статикалык хостинг. Telegram боттун токенин script.js же index.html ичине салууга болбойт.
Автоматтык Telegram жөнөтүү керек болсо, api/rsvp.js (Vercel) же netlify/functions/rsvp.js (Netlify) сервердик функция катары колдонулуп, TELEGRAM_BOT_TOKEN жана TELEGRAM_CHAT_ID хостингдин Environment Variables бөлүмүндө сакталууга тийиш.

Эгер эски токен GitHub'да мурда жарыяланган болсо, BotFather аркылуу /revoke кылып жаңысын алуу керек. Жаңы токенди GitHub репозиторийине жүктөбөңүз.
